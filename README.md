# news-image-20261123

make.fun bounty entry: a 1024×1024 image summarizing the world news of
**23 November 2026** in one front-page composition.

The image was rendered from `page.html` (pure HTML/CSS/SVG, no external
assets) with headless Chrome, then copied to the output directory by
`main.ts` (Node 22 stdlib only).

## Stories covered

1. Quantum "high-speed memory" — world's first QRAM on the Tianmu 2 chip (Nature Physics)
2. Riemann hypothesis proof passes Lean formal verification (Lean & Mathlib)
3. Shenzhou-24 crewed mission cleared for launch (Xinhua)
4. GTA VI sets $3.8B first-day record — biggest entertainment launch ever (Take-Two)
5. Tesla rolls out FSD V15 with Reality View (Tesla)
6. Supermoon on 24 Nov opens a trio of supermoons (CCTV)
7. China's EV charging network tops 25 million units (CCTV / MIIT)

## Usage

```bash
MAKEFUN_OUTPUT_DIR=out node main.ts
```
